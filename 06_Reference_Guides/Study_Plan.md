# Eight-week hands-on plan
1. **B01–B10:** run three contracts per lab, explain each output, and identify every validation boundary.
2. **B11–B20:** compare mechanisms rather than memorizing API names. Write one new failure test per lab.
3. **I01–I10:** compose workflows, inspect SDK/runtime boundaries, and rehearse mechanisms aloud.
4. **I11–I20:** practice debugging, coverage, context, and evaluator tradeoffs. Use the interview rubric.
5. **A01–A10:** state a failure model for every design. Test restart, timeout, policy, and measurement boundaries where relevant.
6. **A11–A20:** address privacy, consistency, operational limits, provenance, and release decisions.
7. **C01–C05:** implement the extension exercises and show acceptance evidence without source completion steps.
8. **Mock interview:** use the five-round session, revisit weak mechanisms, and explain the difference between locally verified behavior and optional live services.

Use 60–90 minute sessions: predict → execute → inspect → break → repair → explain. Keep a notebook of counterexamples and the invariant each test protects. See docs/COVERAGE.md for the complete LangGraph topic map.
