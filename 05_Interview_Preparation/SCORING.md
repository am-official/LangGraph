# Interview scoring rubric
| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Mechanism | Incorrect or unsupported | Correct description | Correct description tied to executed evidence |
| Failure reasoning | Happy path only | Names a plausible failure | Demonstrates a failure and preserves an invariant |
| Design judgment | Lists tools | Identifies a tradeoff | Justifies an alternative under a stated workload/failure model |
| Coding | Incomplete or unsafe | Working main path | Validated inputs, clear errors, acceptance and failure tests |
| Communication | Vague assertions | Understandable explanation | Precise claim, evidence, and limitation |

Use repeated oral explanations and code changes, not memorized wording. Target 8/10 with no zero in mechanism or failure reasoning before moving to a harder topic.
